# Мои траты

Простое Android-приложение для учёта личных доходов и расходов. Данные сохраняются локально на устройстве.

## Возможности

- Добавление дохода и расхода с названием, категорией и суммой в рублях.
- Просмотр операций за выбранный день: дату можно менять стрелками или календарём.
- Круговая диаграмма расходов по категориям за день, неделю, месяц или год.
- Сводка доходов, расходов и баланса за месяц выбранной даты.
- Удаление операций.
- Мягкая светлая тема с фиолетовыми акцентами.

## Сборка APK через GitHub Actions

1. Открой вкладку **Actions** репозитория.
2. Выбери workflow **Build Android APK** и запусти его, если сборка не стартовала автоматически.
3. Дождись окончания сборки, открой её и скачай артефакт `MoiDengi-debug-apk`.
4. Распакуй артефакт и установи `app-debug.apk` на Android.

История хранится в локальных данных приложения. Удаление приложения или очистка его данных удалит историю.

Если у тебя есть старая версия приложения с записями в SEK, значения в хранилище останутся прежними числами, но новый интерфейс будет показывать их как рубли. Пересчёт валюты не выполняется.
